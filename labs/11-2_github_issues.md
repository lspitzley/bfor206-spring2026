# BFOR 206 Lab 11-2: GitHub Issues

## Task Description

Issues are used to track bugs, tasks, and new features for a project.
They help to reduce duplicated work, which in turn reduces errors and
code conflicts.

## Submission Instructions

1. Create an issue on GitHub, or assign an existing issue to yourself (if
no one else is working on it).
2. In your fork of the repository, sync your main branch with the upstream
repository to get the latest changes.
3. Open a codespace on `main`. In the GitHub tab on the left, find the
issue that you are assigned. Click on the arrow `->` next to the
issue title to create a new branch for the issue.
4. Begin working on the issue and commit a change to the branch.
5. Push the push the branch to GitHub. Verify that the commit is visible in the Pull
Request page on the main repository page.
6. When you are ready for feedback, request a review from the instructor `@lspitzley`
in the PR description.
